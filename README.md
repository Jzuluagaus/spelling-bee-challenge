# Spelling Bee Challenge — Smile Alegría

A zero-login, mobile/desktop-friendly spelling practice game.

## Included
- 19 Unit 4 words
- 4-choice spelling recognition
- Hear Word
- Definition
- Sentence clue
- Score + streak
- Missed words return later
- Responsive mobile/desktop layout
- Smile Alegría sponsor banner
- Basic PWA/offline support

## Easiest hosting
1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Sign into Vercel.
4. Import the GitHub repository.
5. Deploy.
6. Optional: connect a custom domain/subdomain such as:
   spellingbee.smilealegria.com

No student login or database is required.
